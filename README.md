# Robot-cad
## Project Objectives
- Design a 3D model of a robot dog.
- Create accurate mechanical parts using CAD software.
- Develop a structure that supports four-legged movement.
- Prepare the design for future manufacturing and assembly.

---
## Robot Components
The robot dog design consists of:

- **Main Body:**  
  The central structure that holds electronic components and supports the legs.

- **Leg Mechanism:**  
  Four legs designed to simulate walking movement.

- **Joints:**  
  Mechanical connections that allow rotation and movement.

- **Foot Design:**  
  Provides stability and contact with the ground.



## Design Process

1. Research existing quadruped robots.
2. Create initial sketches and dimensions.
3. Model individual parts in CAD software.
4. Assemble all components.
5. Check movement and mechanical connections.
6. Export the final 3D model.
